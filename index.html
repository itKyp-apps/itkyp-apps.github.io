Installer

Les applis ne passent pas par le Play Store : Android demande une autorisation la première fois. Une nouvelle version s'installe de la même façon, par-dessus l'ancienne, sans rien perdre.

Google TV ou Chromecast avec Google TV. Un PC est nécessaire une seule fois pour en faire l'accueil.

  1. Sur la TV, installez l'appli Downloader depuis le Play Store, ouvrez-la et tapez le code 3615698 (ou l'adresse itkyp-apps.github.io), puis Télécharger sur la carte TV Launcher.
  2. Autorisez Downloader à installer des applis quand la TV le demande, puis Installer. TV Launcher apparaît dans la liste des applis : vous pouvez déjà l'essayer.
  3. Pour qu'il remplace l'accueil Google (bouton Accueil de la télécommande), désactivez l'accueil Google depuis un PC, en ADB (débogage activé dans les options pour les développeurs de la TV) : 
    adb shell pm disable-user --user 0 com.google.android.apps.tv.launcherx
adb shell pm disable-user --user 0 com.google.android.tungsten.setupwraith
  4. Revenir à l'accueil Google à tout moment : 
    adb shell pm enable com.google.android.apps.tv.launcherx
adb shell pm enable com.google.android.tungsten.setupwraith

Téléphone Android 15 ou plus, avec Android Auto.

  1. Sur le téléphone, touchez Télécharger sur la carte AutoKit, ouvrez le fichier et autorisez l'installation la première fois.
  2. Dans les paramètres d'Android Auto, touchez dix fois « Version » pour activer le mode développeur.
  3. Menu ⋮ puis « Paramètres pour les développeurs » : cochez « Sources inconnues ». Sans ça, Android Auto ne montre pas AutoKit dans la voiture.
  4. Dans la voiture, AutoKit est dans la liste des applis d'Android Auto. Il ne s'utilise qu'à l'arrêt.

Téléphone Android 15 ou plus. Un compte AutoTracks est nécessaire : il se crée dans l'appli (ou sur autotracks.web.app, c'est le même).

  1. Sur le téléphone, touchez Télécharger sur la carte AutoTracks, ouvrez le fichier et autorisez l'installation la première fois.
  2. Ouvrez AutoTracks, puis connectez-vous ou touchez « Créer un compte ». Si vous utilisez déjà le site, vos véhicules, pleins et dépenses apparaissent.
  3. Pour les rappels d'entretien et de contrôle technique, activez-les dans les Paramètres de l'appli : elle demande alors l'autorisation d'envoyer des notifications.
