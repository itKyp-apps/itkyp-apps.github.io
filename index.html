InstallerInstall

Les applis ne passent pas par le Play Store : Android demande une autorisation la première fois. Une nouvelle version s'installe de la même façon, par-dessus l'ancienne, sans rien perdre. The apps are not on the Play Store: Android asks for a permission the first time. A new version installs the same way, over the old one, without losing anything.

Google TV ou Chromecast avec Google TV. Un PC est nécessaire une seule fois pour en faire l'accueil.Google TV or Chromecast with Google TV. A PC is needed once, to make it your home screen.

  1. Sur la TV, installez l'appli Downloader depuis le Play Store, ouvrez-la et tapez le code 3615698 (ou l'adresse itkyp-apps.github.io), puis Télécharger sur la carte TV Launcher.On the TV, install the Downloader app from the Play Store, open it and type the code 3615698 (or the address itkyp-apps.github.io), then press Download on the TV Launcher card.
  2. Autorisez Downloader à installer des applis quand la TV le demande, puis Installer. TV Launcher apparaît dans la liste des applis : vous pouvez déjà l'essayer.Allow Downloader to install apps when the TV asks, then Install. TV Launcher shows up in the app list: you can already try it.
  3. Pour qu'il remplace l'accueil Google (bouton Accueil de la télécommande), désactivez l'accueil Google depuis un PC, en ADB (débogage activé dans les options pour les développeurs de la TV) :To make it replace the Google home screen (the remote's Home button), disable the Google home from a PC, using ADB (debugging enabled in the TV's developer options): 
    adb shell pm disable-user --user 0 com.google.android.apps.tv.launcherx
adb shell pm disable-user --user 0 com.google.android.tungsten.setupwraith
  4. Revenir à l'accueil Google à tout moment :Go back to the Google home screen at any time: 
    adb shell pm enable com.google.android.apps.tv.launcherx
adb shell pm enable com.google.android.tungsten.setupwraith

Téléphone Android 15 ou plus, avec Android Auto.Android 15 or later phone, with Android Auto.

  1. Sur le téléphone, touchez Télécharger sur la carte AutoKit, ouvrez le fichier et autorisez l'installation la première fois.On the phone, tap Download on the AutoKit card, open the file and allow the installation the first time.
  2. Dans les paramètres d'Android Auto, touchez dix fois « Version » pour activer le mode développeur.In Android Auto's settings, tap "Version" ten times to turn on developer mode.
  3. Menu ⋮ puis « Paramètres pour les développeurs » : cochez « Sources inconnues ». Sans ça, Android Auto ne montre pas AutoKit dans la voiture.Menu ⋮ then "Developer settings": tick "Unknown sources". Without it, Android Auto does not show AutoKit in the car.
  4. Dans la voiture, AutoKit est dans la liste des applis d'Android Auto. Il ne s'utilise qu'à l'arrêt.In the car, AutoKit is in Android Auto's app list. It can only be used while parked.

Téléphone Android 15 ou plus. Un compte AutoTracks est nécessaire : il se crée dans l'appli (ou sur autotracks.web.app, c'est le même).Android 15 or later phone. An AutoTracks account is needed: create it in the app (or on autotracks.web.app, it is the same one).

  1. Sur le téléphone, touchez Télécharger sur la carte AutoTracks, ouvrez le fichier et autorisez l'installation la première fois.On the phone, tap Download on the AutoTracks card, open the file and allow the installation the first time.
  2. Ouvrez AutoTracks, puis connectez-vous ou touchez « Créer un compte ». Si vous utilisez déjà le site, vos véhicules, pleins et dépenses apparaissent.Open AutoTracks, then sign in or tap "Create an account". If you already use the website, your vehicles, fill-ups and expenses show up.
  3. Pour les rappels d'entretien et de contrôle technique, activez-les dans les Paramètres de l'appli : elle demande alors l'autorisation d'envoyer des notifications.For servicing and inspection reminders, turn them on in the app's Settings: it then asks for permission to send notifications.
